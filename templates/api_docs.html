Entity Manager API

Every call needs the API token from the add-on's settings page, sent as Authorization: Bearer <token> or as X-API-Key: <token>.

Which callers are answered at all is the add-on option external_access; how far the token reaches is external_api. The web interface itself is never served over the published port.
