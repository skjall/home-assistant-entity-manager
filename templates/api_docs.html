Entity Manager API

A call over the published port needs the API token from the add-on's settings page, sent as Authorization: Bearer <token> or as X-API-Key: <token>. Put it in under Authorize to try a call out.

Read through Home Assistant, this page is already signed in, so the second server in the list answers without a token. That is a different door from the one described here.

Which callers are answered over the port at all is the add-on option external_access; how far the token reaches is external_api. The web interface itself is never served over the published port.
